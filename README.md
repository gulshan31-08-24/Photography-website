# 📸 Photography Portfolio Website (HTML + CSS)

A clean and responsive photography portfolio website built using **HTML** and **CSS**. This site is designed to showcase stunning visuals in a grid or gallery layout, perfect for photographers, artists, or designers.

## 🔗 Live Demo

👉 [Click here to view](https://gulshan31-08-24.github.io/Photography-website/)



## 🌟 Features

- 🧑 About Me section
- 📞 Contact section with form layout
- 🌐 Fully responsive design using Flexbox/Grid
- 🎨 Elegant visual presentation using CSS only
- 🖼️ Hover effects and image zoom-in/out (if CSS used)


## 🛠️ Technologies Used

- **HTML5** – Markup structure
- **CSS3** – Styling and layout
- **Google Fonts** – Typography
- **Responsive Design** – CSS Flexbox or Grid
